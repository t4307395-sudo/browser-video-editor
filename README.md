# ClipForge — محرر فيديو بالمتصفح

محرر فيديو عربي خفيف يعمل بالكامل داخل المتصفح، بدون خادم وبدون رفع الملفات إلى أي جهة. يدعم رفع فيديو، قص البداية والنهاية، التحكم بالسرعة والسطوع والتباين، فلاتر بسيطة، إضافة نص، التحكم بالصوت، وتصدير WebM.

## التشغيل محليًا

افتح `index.html` مباشرة، أو شغّل أي خادم ملفات ثابت مثل:

```bash
python3 -m http.server 8080
```

## النشر على GitHub Pages

المشروع مجهز بملف GitHub Actions في `.github/workflows/pages.yml`، وسيُنشر تلقائيًا عند الدفع إلى فرع `main`. من إعدادات المستودع اختر Pages ثم Source: GitHub Actions إذا لم يتم تفعيله تلقائيًا.

> ملاحظة: التصدير يعتمد على MediaRecorder ويدعم أفضل على Chrome وEdge وFirefox الحديثة. لا يتم إرسال الفيديو إلى الخادم.
